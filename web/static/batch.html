Batch predictionپیش‌بینی گروهی

Paste up to 200 names or SMILES (one per line), or load a CSV file, and download all predictions as a spreadsheet. Useful for a lab class list or a whole homework set.تا 200 نام یا SMILES را وارد کنید (هر خط یکی) یا یک فایل CSV بارگذاری کنید و همهٔ پیش‌بینی‌ها را به‌صورت جدول دریافت کنید. برای فهرست مواد آزمایشگاه یا یک مجموعه تمرین کامل مناسب است.

In a CSV with a header row, the column called smiles (or name) is used; otherwise the first column. Batch mode works fully offline: it knows the 225 built-in names (English or Persian), any SMILES, and salt formulas.در فایل CSVِ دارای سطر عنوان، ستون smiles (یا name) خوانده می‌شود؛ وگرنه ستون نخست. حالت گروهی کاملاً بدون اینترنت کار می‌کند: 225 نام داخلی (فارسی یا انگلیسی)، هر SMILES و فرمول نمک‌ها را می‌شناسد.
